# Projektor receiver

Projektor's look on TVs it casts to with Google Cast: a stylesheet and
pictures for Google's Styled Media Receiver, served by GitHub Pages.

The Cast developer console has its address as the receiver's skin URL:
https://theburek.github.io/Projektor-receiver/projektor.css

Everything here but this README is made by `tool/make_icons.py` in the
Projektor repository, from its `branding/` folder. Rerun that and commit here
after the branding changes.
